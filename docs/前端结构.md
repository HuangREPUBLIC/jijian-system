# 前端代码怎么找、怎么改

前端没有构建工具，`public/js/` 下是一堆普通脚本，由 `public/index.html` 按顺序一个个加载。
所有脚本共用一个全局作用域，所以函数和变量不用 import，直接按名字用。

## 一个功能 = 一个文件

以「薪资管理」为例，打开 `public/js/payroll.js`，里面按顺序是三块：

| 块 | 写法 | 干什么 |
|---|---|---|
| 进页面前拉数据 | `LOADERS.payroll = async () => {…}` | 进这个页面前要调哪些接口、结果写进 `state` |
| 页面渲染 | `function vPayroll() {…}` | 返回这个页面的 HTML 字符串 |
| 按钮动作 | `Object.assign(A, { editPay() {…}, … })` | HTML 里 `onclick="A.editPay()"` 调用的处理函数 |

## 加载顺序（不能乱）

`index.html` 里的顺序：`util → brand → state → api → 通用件（ui、parts、photos、viewer、router、shell）→ 各功能 → pull_refresh → pwa → boot`。

- `state.js` 的初始值在加载时就会调用 `util.js` 的 `todayStr()`，所以 `util.js` 必须在它前面。
- 各功能文件里的 `Object.assign(A, …)` 和 `LOADERS.xxx = …` 需要 `state.js`（定义 `A`）和 `api.js`（定义 `LOADERS`）已经加载。
- `boot.js` 会立刻启动应用，必须最后加载。
- 函数只在被调用时才查找，所以函数体里用到别的文件的函数，不受顺序影响；只有「加载时就要执行」的顶层语句才受影响。

## 加一个新页面

1. 新建 `public/js/xxx.js`，写 `LOADERS.xxx`、`vXxx()`、`Object.assign(A, {…})`。
2. `router.js`：把页面名加进 `VIEW_SET`；是子页面就在 `SUB_VIEWS` 写上级页面；离了 id 没内容的页面加进 `NEEDS_ID`。
3. `shell.js`：`pageMeta()` 里加页面标题，`render()` 里的 `views` 表加 `xxx: vXxx`。
4. `index.html`：在 `boot.js` 之前加 `<script src="/js/xxx.js"></script>`。
5. `sw.js`：`SHELL` 里加 `"/js/xxx.js"`，并把 `CACHE` 版本号 +1。

## 改完前端要做的事

每次改了前端，把 `public/sw.js` 里的 `CACHE` 版本号 +1，手机才会丢掉旧缓存拿到新代码。
